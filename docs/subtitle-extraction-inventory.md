## Required validation before schema creation

1. Record every accepted word's exact input filename(s).
2. Move nonstandard spellings, unresolved homophones, and ambiguous English into uncertainItems; do not create word JSON for them.
3. Label every sound, shape, Chinese-homophone, or folk family explanation as a classroom mnemonic, not etymology.
4. Verify spelling, sense, part of speech, and pronunciation in a dictionary before card creation.
5. Exclude known false claims: scar does not mean threaten; fitness does not mean obesity; stock is not sock; library is not compressed laboratory; and one inch is not 0.83 feet.
