# 待核对项：小学英语词汇助记课

以下内容来自语音转写，尚不满足“拼写明确、基础义明确、课堂方法明确”的正式卡片门槛。已在课程总览的 `uncertainItems` 中同步记录。

| 转写片段 | 候选词 | 为什么暂不制卡 | 建议核对方式 |
| --- | --- | --- | --- |
| Catch / 现金 / 盒子 / 签笔盒 | cash、catch、case、pencil case | 英语词、中文谐音与课堂推导混在一起，无法确定原始拼写和词义链。 | 回听原音或查看教师课件；确认后可分别制卡。 |
| teacher / teacher：一个对多个、一个对一个 | teacher、tutor | 课堂意图可能在对比教师和一对一家教，但 tutor 的拼写未被可靠转写。 | 核对字幕或课件中第二个词的拼写。 |
| floor / float | floor、float、flat | “地板”语义支持 floor，但原始发音、拼写与 flat/float 混淆。 | 查看屏幕板书；以确切单词重新制作卡片。 |
| 草 / grass / straw / sgrace / 死座 | grass、straw、strawberry | 可确认的词与不可靠的口述拼写、声音联想交织。 | 优先核对草杆、吸管和“拉扯”所对应的英文词。 |
| castle / 铸造 / 演员表 | castle、cast | 课程把城堡、铸造和演员阵容串成一段，但严格词源和词形关系不成立或不清楚。 | 核对教师实际板书，分别讲解 castle 与 cast。 |
| sand / 汉语“沙子”来自英语 | sand | 单词本身明确，但关于中英文音义来源的课堂断言不可靠。 | 不需要新增卡；复习时只保留 sand = 沙的基础义。 |
