# Omitted Vocabulary Gap Report — Read-Tool Rescan

## Scope and method

- **Read-only rescan:** 37 unique SRT lesson sources in `input/`; seven hash-suffixed duplicates of lessons 002–008 were excluded.
- **Comparison baseline:** all 217 current `schema/words/*.json` cards.
- **Admission rule:** a candidate must have a stable canonical English spelling, a Chinese base meaning supported by subtitle context, and a replayable classroom image, comparison, sound cue, or word-family explanation.
- **Excluded:** ASR-only spellings, unresolved homophones, clipped root fragments, and words already represented by a current card ID.
- **Important:** sound/shape/Chinese-homophone explanations below are classroom mnemonics, **not** etymology.

Confidence: **H** = spelling + Chinese gloss + mnemonic/scene all explicit; **MH** = spelling and meaning clear, but the mnemonic or Chinese gloss is briefer.
