## 使用说明

1. 先读卡片中的 `classroomMethod`，按课堂顺序复现提问、画面或拆分。
2. 再执行 `rehearsal`；能不看中文说出核心义，才算通过。
3. `caution` 用来防止把课堂联想当成严格词源、拼写规则或全部词义。
4. 转写不可靠的内容只在课程总览的 `uncertainItems` 中保留，不作为正式知识教授。
