# 课堂助记法还原规则

## 还原单位

把一段课堂助记法拆成四个连续单元：

1. **引子**：老师问了什么，或让学生观察/朗读什么？
2. **抓手**：使用了声音、形状、画面、拆分、故事还是词族？
3. **推导**：学生如何从抓手走到词义？
4. **落点**：最终记住的单词、词义或词族关系是什么？

## 写法

优先写具体过程：

- 好：先反复读 bump 的撞击声，再从选项中猜“碰撞”。
- 弱：通过声音联想记住 bump。

## 边界

- 保留课堂的提问和画面，但删除无关直播互动、促销和重复语句。
- 保留“课堂说法”，并在有需要时提示这不是严格词源。
- 当原始过程无法可靠还原时，转入待核对项，而不是补写想象出来的步骤。
