# 背单词知识卡片 Skill

一个独立的课程知识与词汇学习资料生成项目。它面向课程转写文本、课堂笔记或其他学习文案，提取其中的知识结构、单词、词族、记忆画面与复习任务，并生成结构化学习材料。

## 目标

- 从课程转写文本中识别课堂讲解的单词与词族。
- 为每个单词创建独立的学习卡片。
- 保留老师在课堂中使用的具体记忆方法、引导步骤和画面，而非只给出泛化线索。
- 区分“课堂助记法”与“词典释义/严格词源”，避免把课程联想当成事实性结论。
- 生成学习总览、词族路径、复习计划和待核对清单。

## 项目结构

```text
vocabulary-knowledge-cards-skill/
├── input/          # 放入课程转写或笔记（不提交用户内容）
├── schema/
│   ├── knowledge/  # 课程知识、学习路径与待核对项
│   ├── words/      # 每个单词或词组的独立 JSON 卡片
│   └── relationships/ # 课程、知识、单词与词族的节点和边
├── web/            # 读取 schema 的交互式关系图与卡片页面
├── templates/
├── references/
└── examples/
```

## Schema 输出

转换后的正式内容只写入 schema/，不写入 output/。Web 项目从 schema/ 读取知识、单词和关系数据，展示图谱和对应单词卡片。

## 处理原则

1. 优先保留课程原始记忆步骤，例如声音模仿、图像联想、拆分顺序和词族扩展。
2. 对语音转写中不确定的英文单词，标记为“待核对”，不作为确定拼写教学。
3. 每张卡片应包含：核心释义、课堂原始记忆方法、复现动作、使用提醒和自检项。
4. 词汇、词义和词源的最终核对以可靠词典为准。

## Skill 包结构

- [SKILL.md](SKILL.md)：Skill 的正式入口、触发说明和执行工作流。
- [templates/](templates/)：知识、单词、待核对项和关系数据的内容模板。
- [references/](references/)：可信度判定、课堂助记法还原、关系图和卡片质量规则。
- [examples/](examples/)：小型输入与期望 Schema，用于理解和验证 Skill 的行为。
- [schema/](schema/)：可被 Web 直接读取的正式课程、单词与关系数据。
- [web/](web/)：搜索、旋转定位和单词卡片展示页面。

项目目录用于版本化 Skill 内容；要在 DSH 中直接调用时，仍需将 SKILL.md 的内容注册为用户 Skill。
